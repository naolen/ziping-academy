# 子平学堂 · 八字五阶学习系统

按「五阶递进」路径系统学习子平术（八字）的离线学习应用。含 32 张知识卡、40 道精编题，以及 21 类由规则实时推导的题目生成器——题库不会刷完，因为答案不是背的，是算出来的。

在线使用：<https://naolen.github.io/ziping-academy/>

![仪表盘](./docs/preview.png)

> 本项目只练**规则**（五行、藏干、十神、刑冲合害、遁法、旺衰、格局、运程），不含真实历法数据。实际排盘仍需对照万年历，尤其节气交界与子时换日两处。

## 五阶路径

| 阶段 | 内容 | 建议时长 | 知识卡 |
| --- | --- | --- | --- |
| 第一阶 · 符号层 | 干支五行、藏干、十神、刑冲合害 | 1–2 个月 | 9 |
| 第二阶 · 历法层 | 节气定月、五虎遁、五鼠遁、真太阳时 | 2–4 周 | 6 |
| 第三阶 · 结构层 | 月令取格、旺衰、调候、三法冲突 | 3–6 个月 | 8 |
| 第四阶 · 象法层 | 十神心性、宫位、大运流年、应期 | 6 个月起 | 5 |
| 第五阶 · 实证层 | 命例卡、反推验证、可证伪表述 | 长期 | 4 |

第三阶是分水岭：真正的功课不是背会三套方法，而是三套方法冲突时你采信哪一套、为什么。

## 功能

- **学习路径**：知识卡按依赖顺序排列，每张含讲解、表格、例子与易错提示；十神速查表 100 格全部由算法实时生成。
- **无限题库**：21 类生成器（五行、藏干、十神、六冲六合六害、三合、六十甲子、五虎遁、五鼠遁、旺相休囚死、通根、大运顺逆与起运）随机抽参数、按规则推答案，配合 40 道精编概念题。
- **即时解析**：每题作答后给出推导过程，而不只是对错。
- **错题本**：答错自动收录，答对自动移出；错得多的排在前面。
- **弱项专练**：按知识点正确率（低于 70%）抽题，而不是按错题数量。
- **进度与统计**：知识点掌握度、总正确率、连续学习天数；数据存在浏览器本地，不上传任何服务器。
- **键盘操作**：`1–9` 选项，`Enter` 提交 / 下一题。
- **跨设备同步（可选）**：一个同步码就能让公司电脑和手机共用进度，不用注册、没有密码；不开启则完全本地。
- **导出 / 导入**：进度可导出为 JSON 文件，换设备或备份都不依赖任何服务。

## 跨设备同步（可选）

默认纯本地。要跨设备共用进度，需要一处能存数据的地方（GitHub Pages 只发静态文件，存不了数据）。推荐 Supabase 免费版：

1. 在 [supabase.com](https://supabase.com) 新建项目。
2. 打开 SQL Editor，执行 [`supabase/schema.sql`](./supabase/schema.sql)。
3. 在 Project Settings → API 复制 **Project URL** 与 **anon public key**（新版控制台里叫 **Publishable key**，以 `sb_publishable_` 开头）。
4. 打开应用的「设置」页，把这两项填进去，点「在这台设备创建同步码」。
5. 另一台设备同样填后端配置，选择「输入已有同步码」，输入同一串码即可。

**同步码就是钥匙。** 表对匿名用户完全关闭（不建 RLS 策略，并收回表权限），读写只能通过两个 `security definer` 函数，必须传入正确的码才能命中对应行。所以即使拿着公开的 anon key，没有码也读不到、写不了任何一行。码不要公开发出去。

同步码走请求体而不是自定义请求头，是为了绕开浏览器跨域预检对自定义头的限制。

**冲突策略**：整体覆盖，后写胜出。改动后 1.5 秒自动推送；打开页面或切回标签页时自动拉取。覆盖前会保留一份本机快照，可在设置页「恢复同步前的进度」回滚。单人双设备几乎不会撞；同一时刻两台都在答题时，后同步的会覆盖先同步的。

**自检后端**：建好之后可以跑一次，确认权限配置没问题。

```bash
npm run check:sync -- --url https://xxxx.supabase.co --key eyJhbGciOi...
```

它会依次验证：写入、用同一个码读回、错误码读不到、表不能被匿名列举。四项都过才说明配置正确。

**把后端写进部署**（这样打开网址就能直接同步，不用每人手填）：在仓库 Settings → Secrets 里加 `VITE_SYNC_URL` 和 `VITE_SYNC_KEY`，构建时注入。

## 技术栈

- **Vite 7** + **React 19** + **TypeScript**（strict）
- **React Router 7**（HashRouter，静态托管无需服务端重写规则）
- **Vitest** 单元测试
- 手写 CSS 设计令牌，无 UI 框架依赖
- GitHub Actions 自动部署到 GitHub Pages

## 本地运行

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 类型检查 + 生产构建，产物在 dist/
npm run preview    # 预览构建产物
npm test           # 单元测试
```

要求 Node.js 20.19+ 或 22.12+。

## 项目结构

```
src/
  data/        基础表、五阶、知识卡、精编题
  lib/         十神推导、题目生成器、组卷与判分、本地存储
  store/       React Context：学习进度、答题会话
  components/  布局、图标、进度环、阶段行、十神表
  pages/       仪表盘、学习路径、知识卡、刷题、答题、结果、错题本、统计、设置
supabase/      同步表与行级权限 SQL（可选）
```

## 数据与隐私

默认情况下所有学习进度保存在浏览器 `localStorage`（键 `ziping-academy-v2`），不发送到任何服务器。旧版单文件应用的进度（`ziping_academy_v1`）会在首次打开时自动导入一次。

只有你主动开启同步后，进度才会写到你自己的数据库；同步内容是已学标记、答题统计与错题，**不含生辰**。
